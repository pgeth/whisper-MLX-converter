Активация venv: `source venv/bin/activate`  
Выход: `deactivate`

📝 Использование:
`   python run.py <путь_к_папке>`

Скрипт находит в папке все аудио/видео (mp4, mov, mp3, m4a, wav и др.), транскрибирует по очереди и сохраняет текст в ту же папку как `имя_файла_transcript.txt`.

Для длинных файлов: аудио режется на чанки по 60 сек (нужны **ffmpeg** и **ffprobe**), текст дописывается в файл по мере обработки — можно смотреть вывод до конца (`tail -f …_transcript.txt`). В консоли показывается прогресс: чанк N/M, % и ETA.

💡 Пример:

```bash
   python run.py /Users/name/Videos/lectures
```
